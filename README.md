One original one-line office joke, written for the [One-Line Office Joke Laugh-Off](https://make.fun/competitions/u-suzy-one-line-office-joke-laugh-off-f574ac73) bounty on make.fun.

`main.py` (Python 3.13, stdlib only) writes the joke to `/output/entry.txt`. Run it with `python3 main.py`, or `python3 main.py --check` to see the tournament scores, or `python3 main.py --self-test` to verify the output round-trips byte-identically.
